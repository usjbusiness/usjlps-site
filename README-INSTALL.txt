LPS v7 — FULL EXPERIENCE / ПОЛНЫЙ САЙТ
======================================
Это локально подготовленная версия. Живой сайт не изменён.
Основа: сохранённая версия ДО упрощённого редизайна. Не v6.

СОСТАВ
Главная: центральный большой winged mark, весь исходный Canvas-dial
(специальности, вращение, импульсы, блики и частицы), раскрытие логотипа,
световой sheen, parallax, animated text, marquee, счётчики, ВСЕ 8 программ,
горизонтальная scroll-сцена на desktop и native swipe с кнопками на телефоне,
отрисовка иконок, tilt-постер, 5 металлических рангов, magnetic buttons,
hover spotlight, floating phones, сертификаты, живой календарь, все 7
board roles, advisors, Major Leads, 4 шага membership и полный footer.
Фото кампуса — отдельная широкая панорама после вступления, не вместо логотипа.
Картинки Home/Rank — интерфейс настоящего портала с демонстрационным аккаунтом.
For Speakers: полная отдельная страница, 4 преимущества, формат вечера,
Path Library, контакты, скрытая галерея до появления настоящих фото.
Apply: прежний backend, форма и валидация. Чужие данные не менялись.
Ни одного выдуманного имени/портрета члена правления: пока показаны роли.

УСТАНОВКА (не Members и не E-Board)
1. Скачай ZIP и РАСПАКУЙ на компьютере.
2. Репозиторий публичного сайта: usjbusiness/usjlps-site.
3. Содержимое ZIP сразу в КОРЕНЬ репозитория. Не в website/ и не в site-v7/.
   Этот архив БЕЗ внешней папки. В корне: index.html, join.html, speakers.html,
   CNAME, .nojekyll, assets/, join/, speakers/ и документы.
4. Замени ВМЕСТЕ index.html, assets/site.css, assets/site.js и остальные файлы
   из архива. Не заменяй один index.html отдельно: это несовместимые сборки.
   Версии CSS/JS помечены ?v=lps7, чтобы не подхватить старый браузерный кеш.
5. Не удаляй существующие .github/workflows, DNS, CNAME usjlps.org или Secrets.
6. Дождись успешного GitHub Pages deploy. Открой главную, /join.html,
   /speakers.html, /join/ и /speakers/. Проверь desktop и телефон.
7. Публичный календарь использует тот же STEP19, что и v6. Если он уже
   установлен, НИЧЕГО в Supabase повторно делать не нужно. Если нет — SQL
   в LPS-STEP19.sql; требуется ранее установленный STEP18. Дизайн работает
   независимо; без RPC показывается честное сообщение календаря, не фейковые даты.

PREVIEW

Навигация Home / For Speakers / Apply в верхней панели, и обычные ссылки
внутри сайта тоже работают. Все фотографии, CSS, шрифты и JS включены.

заявка не создаётся, письма не отправляются. Preview НЕ production index.html!
