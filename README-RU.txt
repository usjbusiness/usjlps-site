LPS — локальная версия нового сайта (v9).

Откройте index.html через HTTP-сервер, например: python3 -m http.server 8000; затем откройте http://localhost:8000. Для статистики, формы и внешних ссылок нужен интернет.

Статистика использует тот же публичный RPC site_stats, что и существующий сайт; отображает только агрегированные значения members и eboard, а не персональные данные. Запрос выполняется при загрузке и каждые 5 минут во время посещения; при ошибке вместо выдуманного числа выводится предупреждение. Значение members подписано нейтрально: смысл его серверной выборки нужно подтвердить на стороне базы перед публикацией.

Счётчики анимируются при появлении на экране; для prefers-reduced-motion анимация отключена. Изображение портала — реальный экран с демонстрационными данными, не рабочая интерактивная форма.

Гостевая страница восстановлена по действующей странице guests.usjlps.org; её форма готовит черновик письма в почтовом приложении, не отправляет заявку автоматически. Страница заявки join.html использует существующий RPC submit_member_application и должна проверяться с владельцем перед публикацией. Старые ссылки original/index.html удалены из навигации; на прежних адресах размещены короткие перенаправления вместо старой страницы.

Это готовая к проверке локальная сборка, не автоматическая публикация. Перед размещением проверьте доступность API и формы на конечном домене, ссылки, актуальность команды и прав на материалы.
