LPS v10 — локальная версия для проверки; не опубликована.
Запустите python3 -m http.server в этой папке и откройте localhost:8000.

Добавлены прозрачные значки, портреты существующего E-Board, публичный календарь на существующем API и прямой переход к программам. Старая ссылка #experience ведёт к программам. Календарь показывает будущие записи, доступные через публичный RPC, в восточном часовом поясе, обновляется каждые 30 секунд; при ошибке отображается состояние подключения. Тестовые мероприятия не добавлялись.

Индивидуальный адрес добавлен только для Никиты: он уже опубликован на гостевой странице. Для остальных используется общий опубликованный адрес hello@usjlps.org; индивидуальные адреса нужно уточнить перед добавлением. Роли и фотографии взяты с прежнего сайта LPS и требуют подтверждения актуальности перед публикацией.

Проверить серверные данные, доступность API на конечном домене, заявку и права на материалы перед развертыванием.
